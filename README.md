Employee Workforce Analytics Using Microsoft Excel
Data Analytics Portfolio Project | Beginner Level

Project Overview:
An Excel-based data analysis project using 500 fictional employee records to analyse workforce distribution, salary information and employment status.

Tools Used:
Microsoft Excel

Excel Functions and Features
* SUM, AVERAGE, COUNT, COUNTA
* MAX, MIN, COUNTIF
* IF and IFS
* Conditional Formatting
* Sorting
* Excel Tables

Analysis Performed

1. Workforce Overview
* Total Employees: 500
* Active Employees: 336
* Employees On Leave: 87
* Resigned Employees: 77

2. Salary Analysis
* Total Monthly Salary: ₹2,96,02,000
* Average Monthly Salary: ₹59,204
* Highest Salary: ₹1,00,000
* Lowest Salary: ₹18,000

3. Department-wise Analysis
* Employee distribution across eight departments using COUNTIF.
